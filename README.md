# Boussole 2027

Quiz politique à verdict aveugle pour l'élection présidentielle française de 2027.

20 propositions, 8 thèmes de priorité, 11 candidatures documentées. Aucun nom de
candidat n'apparaît avant l'écran de verdict. Le résultat affiche le classement,
les points de désaccord et un indicateur de fiabilité.

## Méthode

- Positions codées de −2 à +2 à partir des documents de campagne publiés au 22/10/2026.
- Score normalisé sur les seules propositions où le candidat a une position publiée.
- Candidat écarté du classement en dessous de 6 positions documentées.
- Candidatures sans programme exploitable listées explicitement.

## Limites

Le codage est une interprétation de l'auteur, pas une parole des candidats.
Un programme de campagne n'est pas un programme de gouvernement ; les professions
de foi officielles n'existeront qu'en avril 2027.

Fichier unique, sans dépendance, sans collecte de données.
